Este projeto foi criado com a turma do 9º ano do programa **Formando Crianças para o Futuro 2026** para explorar duas ideias ao mesmo tempo:

- **vibe coding**: aprender a criar com apoio de IA, usando prompts claros para orientar lógica, design e refinamento;
- **impacto social**: mostrar como a tecnologia pode fortalecer educação, criatividade, colaboração e pensamento crítico.

## Sobre o projeto

A aplicação é um **simulador da Copa do Mundo de 2026** baseado no Grupo C, com foco no Brasil.  
O conteúdo foi pensado para engajar os alunos com um tema próximo, divertido e visualmente marcante, ao mesmo tempo em que trabalha conceitos de:

- organização de interface;
- interação com o DOM;
- variáveis CSS;
- validação automática de tarefas;
- leitura crítica de instruções geradas por IA.

## Vibe coding na prática

Neste projeto, os estudantes não precisaram começar do zero escrevendo tudo manualmente.  
Eles atuaram como **diretores de lógica**: descreveram o que queriam, revisaram o resultado e ajustaram o projeto com novos prompts até chegar ao resultado desejado.

Isso ajuda a desenvolver uma habilidade importante para o presente e o futuro: **saber pensar, pedir, revisar e melhorar**.

## Impacto social

O projeto incentiva:

- acesso à tecnologia de forma criativa e responsável;
- protagonismo dos estudantes no processo de aprendizagem;
- trabalho em equipe;
- confiança para experimentar e resolver problemas;
- uso da IA como apoio educacional, e não como substituição do raciocínio.

Mais do que um simulador de futebol, esta experiência mostra que a programação pode ser uma ferramenta de inclusão, expressão e aprendizagem significativa.

## O que os alunos aprenderam

- Como a IA pode ajudar no desenvolvimento de software.
- Como usar prompts para orientar um resultado.
- Como identificar e corrigir problemas em uma interface.
- Como transformar uma ideia em uma experiência interativa.

## Como executar

Abra o arquivo `index.html` no navegador.
